# Website Project 1

Een persoonlijke profielwebsite van Harsha Kanaparthi, gemaakt voor project 1 van de opleiding HBO-ICT aan de Hogeschool Utrecht. De website presenteert mijn achtergrond, interesses, opleiding, werkervaring en certificaten.

## Inhoud

- Persoonlijke introductie en profiel
- Interesses in cyber security, cloud computing, netwerken en systeembeheer
- Opleiding en stage-ervaring
- Behaalde certificaten
- Contactgegevens en externe profiel-links
- Privacy-informatie voor bezoekers

## Technologie

- HTML5
- CSS3
- JavaScript
- SVG en PNG-afbeeldingen
- PlantUML voor ontwerpdiagrammen

Er is geen framework of buildproces nodig. De website bestaat uit statische bestanden en werkt direct in een moderne webbrowser.

## Website lokaal bekijken

1. Clone deze repository:

   ```bash
   git clone https://github.com/Harsha2006217/Website-Project-1-.git
   ```

2. Open `11_Website/website/index.html` in een webbrowser.

Voor de beste lokale ontwikkelervaring kan de website ook met een eenvoudige lokale webserver worden gestart, bijvoorbeeld:

```bash
cd 11_Website/website
python3 -m http.server 8000
```

Open daarna <http://localhost:8000>.

## Toegankelijkheid en privacy

De website bevat onder andere een skip-link, semantische HTML, beschrijvende alt-teksten, toetsenbordvriendelijke navigatie en een responsive mobiel menu. De pagina gebruikt geen cookies, analytics of trackers. De JavaScript draait uitsluitend in de browser en verzendt geen gegevens naar een server.

## Ontwerp en screenshots

De map `12_Screenshots` bevat voorbeelden van de website op desktop, tablet, mobiel en bij 200% zoom. De map `13_Ontwerp` bevat de wireframes, de paginastructuur en de oorspronkelijke schetsen.
